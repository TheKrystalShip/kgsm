# KGSM Documentation

How the engine works and how to use it.

- [Commands](commands.md): the command surface, output formats, exit codes and provenance.
- [Blueprints](blueprints.md): the file that declares a game server, and where blueprints live.
- [Hooks](hooks.md): a game's own version check, download and deploy steps.
- [Instances](instances.md): an installed server, its files, its config and its management script.
- [Libraries](libraries.md): the storage roots instances are placed in.
- [Configuration](configuration.md): the engine's settings, its files and its log.

The event vocabulary, the journal, the action manifest and the wire contracts are documented once, in the
`kgsm-docs` repository.
